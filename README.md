# PHP Projects – ToDo List & Calculator

This repository contains two basic PHP projects built using PHP and MySQL:

- ✅ Simple **ToDo List** application
- ✅ Simple **Calculator** application

Both projects are great for beginners who want to understand form handling, basic PHP logic, and database integration.

---

## 🚀 Projects Overview

### 📋 1. ToDo List App

A simple task manager where users can:

- Add tasks
- Edit tasks
- Delete tasks
- Store data using **MySQL**

#### 🔧 Technologies Used

- PHP
- MySQL
- HTML/CSS
- Bootstrap (for minimal styling)
